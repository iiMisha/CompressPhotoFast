# AGENTS.md — шаблон и паттерны

Reference для скилла `agents-updater` (CompressPhotoFast).

## Лаконичность по умолчанию

- Лаконичность — требование к КАЖДОЙ правке с самого начала, а не реакция на превышение лимита. Телеграфный стиль: факты, имена файлов/классов/команд, без связок и вводных оборотов («было добавлено», «решили», «для того чтобы»).
- Новая запись ≤ 2-3 строк; правка существующей не раздувает её размер. Обоснования — в коммитах и логах, не в AGENTS.md.
- Тест на достаточность: если после удаления формулировка теряет факты — вернуть; если только стиль — оставить короткую версию.

## Лимит размера: ≤ 15000 токенов

- Оценка: `токены ≈ символов / 4` (русский текст ≈ `/ 2.5`). Проверка после любого изменения: `wc -c AGENTS.md` → ≈ 37 КБ для русского ≤ 15000 токенов.
- При превышении, по порядку:
  1. Самые старые записи из «Актуального контекста».
  2. Неактуальные шаги из «Рабочего процесса».
  3. Сократить описания секций до essentials.
- Компактность: предложение вместо абзаца, списки, только факты, ссылки на файлы вместо кода; ❌ примеры кода, таблицы, глубокая вложенность, дублирование.

## Структура AGENTS.md (фактическая)

```markdown
# CompressPhotoFast
Одно предложение: утилита сжатия фото с EXIF, Android + Python CLI, язык проекта, версия.

## Быстрые правила
- Навыки `apk` / `android-test-suite`, ограничения Android, правило test/androidTest.

## Стек
- Android: Kotlin, Coroutines, Hilt, WorkManager, ...; minSdk/targetSdk.
- Тесты: JUnit, MockK, Robolectric, Espresso, JaCoCo.
- CLI: Pillow, pillow-heif, piexif, Click, Rich, tqdm, ProcessPoolExecutor.

## Архитектура Android
- UI / Сжатие / Настройки и данные / Инфраструктура / Мониторинг / CLI — пути файлов.

## Инварианты сжатия
- 100 КБ минимум; ≥30% + 10 КБ; EXIF-маркер; RGB_565/admission; parity с Python.

## Актуальный контекст
- Действующие решения и механизмы (телеграфно, 1 строка на факт).

## Проверка и релиз
- Команды сборки/тестов/релиза, где обновлять версию.

## Рабочий процесс
1-5. Пошаговый цикл: код → сборка → тесты → agents-updater → apk.
```

## Паттерны анализа (`initialize`)

Определение стека: `app/build.gradle.kts` (Android), `compressphotofast-cli/pyproject.toml`/`requirements.txt` (Python), `gradle.properties` (версия).

Сбор информации (точечно, не всё сразу; бюджет чтения — вписаться в лимит):
```
Glob("app/src/main/java/**/*.kt")
Glob("compressphotofast-cli/src/*.py")
Grep("@Module|@HiltViewModel", "app/src/main/**/*.kt")
Read("app/build.gradle.kts") + Read("gradle.properties")
```

## Формат задачи (`add_task`)

Макс 15 строк, без кода:
```markdown
### Краткое название
**Когда**: … **Файлы**: … **Шаги**: 1. … 2. … **Важно**: …
```

## Обновление (`update`)

`git log --oneline -10 --name-only` вместо чтения файлов; `focus_source` — конкретный файл. После — проверка лимита `wc -c`. Историю («что было сделано» с нарративом) в AGENTS.md не возвращать: факты → «Актуальный контекст» одной строкой, детали → коммит.
