# Apk

Скилл публикует собранный APK (по умолчанию **debug**; `--release` — release-вариант)
`http://<host>[:<port>]/<token>/app-debug.apk` (`<token>` = 32 hex-символа).
Листинг директорий закрыт, чужие пути → 404, APK отдаётся с правильным MIME
и `Content-Disposition: attachment`. По истечении TTL файл автоматически
удаляется, метаданные ссылок хранятся вне веб-корня.

**Режим без sudo** — `scripts/share_nosudo.py`:

| | **Без sudo** |
|---|---|
| Скрипт | `scripts/share_nosudo.py` |
| Права | обычный пользователь |
| Сервер | встроенный `http.server` Python |
| Порт | первый свободный начиная с **8080** (`--port` меняет начало диапазона) |
| Авто-очистка по TTL | поток-таймер в серверном процессе |
| Веб-корень | `~/apk-share-compressphotofast` |
| Метаданные | `~/.local/share/apk-share-compressphotofast` |
| Когда выбирать | нет sudo, либо хочется поднять за секунды без root |

CompressPhotoFast — чистое Kotlin/Java приложение без нативных библиотек
(нет NDK/OpenCV/`.so`), поэтому отдельный compact-билд (arm64-only + сжатые
`.so`) здесь не нужен: скрипт по умолчанию собирает обычный `:app:assembleDebug` (minSdk 29),
APK получается компактным; флаг `--release` даёт `:app:assembleRelease`. Скрипт
находит самый свежий APK в `app/build/outputs/apk/<variant>/*.apk`, поддерживает
`--no-build` (переиспользовать готовый APK), `--ttl`, `--host`, `--list`.

## Режим без sudo (Python HTTP, порт 8080+)

`scripts/share_nosudo.py` поднимает встроенный HTTP-сервер Python на первом
свободном непривилегированном порту, начиная с `8080`. Если `8080` занят,
скрипт автоматически переключается на следующий свободный порт (диапазон из 20)
и печатает его в URL. Не трогает nginx, `/var/www`, systemd. Серверный
процесс запускается отцепленным от терминала (`start_new_session=True`,
эквивалент `nohup ... &`) и сам завершается с очисткой каталога по TTL.

```bash
# Полный цикл без root (порт 8080, TTL по умолчанию 1ч). Запускать из корня проекта.
# По умолчанию — debug.
.agents/skills/apk/scripts/share_nosudo.py

# Release-вариант вместо debug (по явному запросу)
.agents/skills/apk/scripts/share_nosudo.py --release

# Переиспользовать уже собранный APK выбранного варианта
.agents/skills/apk/scripts/share_nosudo.py --no-build

# Другой порт и TTL
.agents/skills/apk/scripts/share_nosudo.py --port 9000 --ttl 6h

# Своё доменное имя
.agents/skills/apk/scripts/share_nosudo.py --host build.example.com

# Список активных / остановить
.agents/skills/apk/scripts/share_nosudo.py --list
.agents/skills/apk/scripts/share_nosudo.py --stop <token>
.agents/skills/apk/scripts/share_nosudo.py --stop-all
```

URL в этом режиме: `http://<host>:<port>/<token>/app-debug.apk`
(для `--release` — `app-release.apk`).
Лог процесса: `~/apk-share-compressphotofast/<token>/server.log`.

Имя скачиваемого файла (заголовок `Content-Disposition`) содержит вариант и
дату/время сборки APK: `CompressPhotoFast-debug-YYYYMMDD-HHMMSS.apk`
(для `--release` — `CompressPhotoFast-release-...`; по mtime файла,
локальное время) — так разные билды различаются на устройстве.

> ⚠️ **Порт 8080 должен быть открыт снаружи.** Поднимается отдельный слушатель.
> Проверьте файрвол / группу безопасности хостера. Сам сервер слушает `0.0.0.0`,
> локальная проверка (`verify_url`) на самом VPS проходит всегда — она не
> гарантирует доступ снаружи.

## Параметры

| Флаг | Назначение |
|------|-----------|
| `--release` | собрать/опубликовать release-вариант (`assembleRelease`, `apk/release/`); по умолчанию debug |
| `--no-build` | не собирать, взять свежий APK из каталога вывода выбранного варианта |
| `--keep` | сохранить старые ссылки и старые APK (по умолчанию удаляются) |
| `--ttl <время>` | срок жизни ссылки. Формат `<число>[s\|m\|h\|d]`, напр. `30m`, `6h`, `2d`. По умолчанию `1h` |
| `--host <host>` | хост/домен в URL (по умолчанию определяется публичный IPv4) |
| `--port <N>` | начать поиск свободного порта с `N` (по умолчанию 8080) |
| `--list` | показать активные ссылки и выйти |
| `--stop-all` | остановить/удалить все ссылки и выйти |
| `--stop <token>` | остановить конкретную ссылку |

## Поведение и гарантии

- **Одна активная ссылка за раз:** при новом запуске автоматически убиваются все старые ссылки (серверы + каталоги + метаданные) и удаляются устаревшие APK в каталоге вывода выбранного варианта (остаётся только самый свежий). Флаг `--keep` отключает обе чистки, если нужно несколько одновременных ссылок.
- **Безопасность:** URL неугадываем (128 бит энтропии); каталоги не листятся; чужие пути → 404. APK отдаётся с `Content-Type: application/vnd.android.package-archive` и `Content-Disposition: attachment`.
- **Докачка (Range):** одиночные диапазоны `bytes=start-end` / `bytes=-N` → 206 + `Content-Range`; невалидный диапазон → 416; multipart → 200 целиком. Обрыв связи не заставляет качать файл с нуля.
- **Занятый порт:** перед запуском проверяется диапазон из 20 портов начиная с `--port`; при занятом `8080` автоматически выбирается следующий свободный порт. URL и метаданные используют фактически выбранный порт.
- **Многопоточный сервер:** поток на соединение; зависший клиент (сокет-таймаут 300 с) не блокирует параллельные запросы и повторное открытие ссылки.
- **Авто-очистка:** по TTL — поток-таймер внутри серверного процесса завершает его и удаляет каталог (`os._exit(0)`).

## Требования к окружению

- Корень проекта определяется автоматически по расположению скрипта (`Path(__file__).resolve().parents[4]`); скрипт запускать из checkout проекта с `gradlew` в корне.
- **НЕ нужен root.** Нужен Python 3 (есть в системе).
- Свободный непривилегированный порт из диапазона `8080..8099` (или диапазона от `--port`), открытый снаружи.
- Публичный IPv4 определяется автоматически через исходящий интерфейс (VPS без NAT) или задаётся `--host`.

## Troubleshooting

- **Ссылка 404 / не открывается с телефона:** проверить, что порт открыт, сервер активен (`--list` показывает живой PID) и что публичный IP определён верно (`--host`). Если автоматически выбранный порт закрыт внешним файрволом, открыть диапазон `8080..8099` или задать разрешённый порт через `--port`.
- **`verify_url` предупреждает, но ссылка локально 2xx:** обычно значит, что порт закрыт снаружи — открыть в файрволе/группе безопасности хостера.
- **Ссылка перестала работать «сама по себе»:** истёк TTL (процесс завершился и удалил каталог) — поднимите заново. Либо перезагрузка VPS убила фоновой процесс — `--list` покажет «МЁРТВ», поднимите новой командой.
- **Сборка падает:** запускать из корня проекта; команда (как в AGENTS.md) — `./gradlew :app:assembleDebug` для debug (по умолчанию), `./gradlew :app:assembleRelease` для `--release`.
